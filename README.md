# FX Compass

Plateforme d'analyse forex (8 devises, 28 paires) : biais quotidien, banques centrales, sentiment retail, COT, calendrier économique, géopolitique. Application de bureau pour Windows 10 / 11.

## Installer

1. Télécharger **[FXCompass-Setup.exe](https://github.com/RayenKnani01/fx-compass/releases/latest/download/FXCompass-Setup.exe)**
2. Double-cliquer dessus. Si Windows affiche « Windows a protégé votre ordinateur » : **Informations complémentaires → Exécuter quand même** (l'application n'est pas signée).
3. Suivre l'installation (quelques minutes la première fois : Python et les bibliothèques s'installent tout seuls).
4. Ouvrir **FX Compass** depuis le bureau ou le menu Démarrer.

## Mises à jour

- **Données** : toutes les 5 minutes (prix, news, publications économiques, Fed, sentiment, scores) et toutes les 30 minutes (macro, COT, banques centrales), automatiquement, tant que le PC est allumé.
- **Application** : les nouvelles versions publiées ici s'installent toutes seules (vérification toutes les 30 minutes).

## Désinstaller

Paramètres Windows → Applications → FX Compass → Désinstaller (supprime aussi les mises à jour planifiées).
